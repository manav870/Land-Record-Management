# Land Record Management - Frontend

React frontend application for the Land Record Management System.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm start
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Configuration

Update the contract address in `src/utils/contract.js` after deploying the contract.

## Features

- MetaMask wallet connection
- Land registration
- Ownership transfer
- Land record viewing
- Ownership history

## Technologies

- React.js
- Ethers.js (v6)
- Tailwind CSS
